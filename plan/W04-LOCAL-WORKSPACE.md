# W04 身份/消息与最小本地工作台实施计划

日期：2026-11-14。现有设计继续执行，用户已要求自主构建、根因修复和完整真实操作检验。

## 范围选择

本轮是 W04 可离线实施部分 + W02 最小交互验证，不是提前宣布 W10/P3 完成。相对于继续堆积后端接口，选择单机主人工作台作为可操作入口；相对于直接连接原客户端，选择持久化离线登记/消息/任务草稿，并为执行级feed提供受信任集成边界。保留原客户端及G0/G1门槛。

- 同源轻量 HTML/CSS/JS，无外部CDN、遥测、模型请求；群列表、成员登记、公开/定向消息、任务草稿、只读概览。
- 主人配对：启动终端展示一次性随机配对码，10分钟有效；换取HttpOnly/SameSite=Strict会话，写请求强制同源与CSRF；注销/超时撤销。配对码不落库、不放URL、不记录到证据。数据库同Windows身份隔离仍未获资格。
- 主人控制面与原core Bearer接口严格分开；成员登记不发grant、不启动原客户端。无真实连接时明确“未连接”“仅本地保存/未发送”。
- 消息事务幂等写入及delivery/outbox。受信任feed绑定必须在策略/grant/channel ACL允许的情况下创建；只交付绑定后的授权消息，不向新grant继承旧私密历史。每页/重试重做授权、成员状态及撤权检查，游标绑定grant/channel且只包含自身feed位置。
- 任务为提案草稿，可创建/编辑/归档，不伪造运行/完成；不绕过core验收/审批/写权限。主人工作台是单主人本地入口，不是假冒多用户系统。
- 数据库002迁移事务且校验历史001；原错误、格式、测试保留。旧空库和已有W03数据库都应可升级。
