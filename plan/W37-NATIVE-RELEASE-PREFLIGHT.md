# W37 · 原生发布前的只读预检

依照 04 章「升级、兼容与回滚」先验证交付物，再讨论签名发布。没有安装、覆盖、重打包、读私钥或用旧程序打开任何数据库。

原有包检查先按清单给出的路径读内容，最后才核对实际目录；另未校验清单字节数或识别硬链接。在合成目录中，错误大小与硬链接曾被判为通过，越界条目则触发目录外文件的打开尝试。现先对根目录与清单做普通本地路径检查，再枚举包中普通、非链接文件，精确核对完整清单，最后检查每个文件字节数及 SHA-256。三个反例均保留在回归中。

本机旧 0.3.0 原生包 989 个文件通过此检查；对其 `Team.exe` 的 Windows Authenticode 只读查询返回 **NotSigned**。这不是整个包的发布者认证：本地哈希清单本身不能证明来源。只读预检不安装、不锁定活跃更新目录，也不是针对并发替换的生产更新器。

生产签名与升级仍需指定发布者和受信签名设施，并安排新版本在独立测试数据上做迁移、回滚验证。在线/离机灾备还需要独立存放位置、加密密钥保管人及恢复验证；W36 同机恢复不能替代异机恢复。Windows 强制隔离继续暂停，原生点击、管家和 250 项产品资格均未升级。
