# W05 — 原生 Windows 工作台

日期：2026-11-14。用户已明确“就是要原生的”；覆盖旧方案的 Electron/Tauri 前端建议，不扩大 Agent 接入授权。

## 决策和范围

- 使用 .NET 10 / WPF 原生控件，单独窗口、任务栏入口；不包含 WebView、Electron、Chromium 或浏览器启动命令。
- 保留 Node 24.14.0 本地服务、SQLite 迁移和 workspace/0.1 安全契约。前端不直读写业务数据库。
- 两栏：项目列表 / 对话与任务。成员和进度按需打开；不做标语、教学卡片或重复状态标签。
- 主窗口只保留一处能力事实：Agent 尚未连接、消息本地保存。任务保持草稿，不冒称派发、审批或执行。
- 不启动 Codex、Claude Desktop、DeepSeek Harness，不调用模型，不增加外部审查代理。

## 实施顺序与检查点

1. **基线与工具链**：保存 W04 源文件 SHA256 快照；设计离线校验。仅在 `.tools` 下载官方 SDK ZIP 并验证 SHA512，不修改系统 SDK。固定 SDK 10.0.404 / runtime 10.0.15（官方元数据发布日期 2026-11-10）。
2. **先写生命周期失败测试**：新的 desktop-entry 等待 stdin `start` 才建库；输出私有 JSON 握手；stdin EOF/`stop` 关闭监听/数据库；原 main.ts 不变。测试必须证实缺入口失败，再实现并通过。
3. **原生宿主和传输**：C# `ServiceHost.StartAsync` 使用绝对可执行路径、禁 shell、隐藏服务窗口、重定向私有管道；Job Object 仅包含所属子进程且关闭即终止。进程赋入 Job 后发 start。配对码/CSRF/cookie 仅内存；HttpClient 使用精确 Origin，禁代理/重定向，解析版本化响应。启动超时/退出可见，重试显式。单数据库独占 lease 文件（进程退出自动释放），拒绝同库重复服务；不终止其他 Node。
4. **客户端状态失败测试**：同一不确定提交重试复用 action_id 和原始载荷；禁止偷偷替换收件人；切项先清空、只采纳最后一次读取；修改冲突保留输入。随后实现 `WorkspaceController` / `CommandAttempt`，测试真实服务认证、消息、成员、草稿、字面搜索、分页、跨项目隔离和重启持久化。
5. **原生布局**：WPF XAML 主窗口和小型表单窗口。Tab/键盘焦点、可访问名称和稳定 AutomationId。请求进行中禁止并发修改；输入暂存按项目，不因查询/刷新丢失；关闭有未保存内容需确认。已提交但刷新失败明确区分。私密收件人或负责人失效必须显式处理。
6. **分发**：自包含 win-x64 目录包含 Team.exe、.NET 桌面运行时、固定 Node 和最小服务依赖；不包含 web 资产/测试库/开发 SDK/数据库/证据/密钥。双击无需 npm、浏览器、手输 URL 或配对码。默认 `%LOCALAPPDATA%\Team\core.sqlite`，`--data <绝对路径>` 指向现有库；不自动迁移或覆盖旧库。
7. **检验**：新增桌面测试 + 原 122 项 Node + build smoke + 原浏览器回归 + 12 项 P0 + 设计工具；真实原生窗口通过受支持 Computer Use 操作验证。若 UI 权限不足，明确记录，不用内部测试冒称用户走查。验证关闭/崩溃只回收所属服务，重开数据不丢失。
8. **交付与自审**：记录文件清单、测试输出、原生截图、可执行目录；更新源章、README、交接及 manifest。作者自审不声称独立审查。250 产品用例仍 NOT_RUN、原客户端兼容 UNVERIFIED、契约 NOT_FROZEN。

## 边界

后台真实 Agent 任务尚不存在，因此此版关闭窗口即关闭自己的本地服务；未来后台执行必须重新设计可见生命周期。此版不证明 Windows 强制安全隔离（Job Object 是本机子进程回收机制，不是安全沙箱）。未签名便携开发包，不声称正式安装器或生产发布。
