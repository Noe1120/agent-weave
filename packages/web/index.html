使用启动终端中的一次性配对码。配对不会启动任何 Agent。

在哪里找到配对码？

在本机终端运行 npm start，打开显示的地址并复制配对码。已使用或过期时，另开终端运行 npm run pair。

配对码 10 分钟内有效，一次使用；会话 8 小时有效。不要将配对码分享给他人。

这是本地协作基础版，不是已接通原客户端的完整平台。
